Sobre o SaldoPlan

CONTROLE FINANCEIRO PESSOAL

SaldoPlan

Uma aplicação multiplataforma criada para organizar a vida financeira, acompanhar o salário por períodos e reunir entradas, gastos, reservas, projeções e simulação de folha em um só lugar.

Web PWA Android Offline Google Drive
RECURSOS

Controle financeiro

✓ Entradas e despesas ✓ Gastos fixos, variáveis e imprevistos ✓ Valores guardados e reservas ✓ Ciclos de quinzena e final do mês ✓ Entradas extras selecionáveis nos ciclos ✓ Projeções financeiras mensais ✓ Histórico por competência ✓ Cartões, faturas e compras parceladas ✓ Patrimônio líquido, dívidas e metas financeiras ✓ Projeção financeira de 30, 60 e 90 dias ✓ Importação PDF/OFX/CSV com detecção de duplicados ✓ Regras inteligentes de categorização
FOLHA

Simulação salarial

✓ Salário base e adiantamento ✓ Horas extras 50% e 100% ✓ Adicional noturno ✓ DSR sobre extras ✓ INSS e IRRF estimados ✓ Competências mensais independentes
PLATAFORMAS

Disponibilidade

🌐 Aplicação Web 📲 PWA instalável 🤖 Aplicativo Android via APK 📴 Funcionamento offline 💻 Compatível com desktop e mobile
DADOS

Backup e segurança

✓ Armazenamento local no dispositivo ✓ Login com conta Google ✓ Backup no Google Drive ✓ Seleção de pasta pelo Google Picker ✓ Exportação JSON e CSV ✓ Restauração de backups
TECNOLOGIAS

Stack do projeto

HTML5 CSS3 JavaScript LocalStorage Service Worker Web App Manifest Firebase Authentication Google Identity Services Google Drive API Google Picker API Git GitHub Vercel
PRIVACIDADE

Seus dados continuam seus

As informações financeiras são mantidas localmente no dispositivo. O acesso ao Google Drive é separado do login e somente é autorizado quando o próprio usuário conecta o serviço para utilizar o backup.
